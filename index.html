Odd Within Analytics

About This Application

Odd Within Analytics is a personal desktop application used by the owner of The Odd Within YouTube channel to analyze channel performance.

The application uses the YouTube Data API and YouTube Analytics API with read-only permissions. It is intended for personal use by the channel owner.

Privacy Policy

This application accesses YouTube channel information and analytics data only with the account owner's authorization.

Retrieved data is stored locally on the owner's computer and is not sold or shared with third parties.

Users may revoke access at any time through their Google Account security settings.

Terms of Service

This application is provided for personal use by the owner of The Odd Within YouTube channel.

The application provides analytics information without any warranty of accuracy or availability.

This application uses YouTube API Services. By using the application, the user agrees to the YouTube Terms of Service.
